StageXL WebGPU Examples

Stencil masks Animated circle masks and nested circle + star masks using WebGPU stencil attachments. Direct bitmap filters ColorMatrixFilter and TintFilter rendering through the WebGPU WGSL filter path. Blur filter Bitmap and sprite BlurFilter rendering through WebGPU offscreen filter passes. Glow filter Bitmap and sprite GlowFilter rendering with WebGPU blur passes, knockout, and hide-object modes. Normal map filter Diffuse + normal texture lighting via NormalMapFilter with a pointer-driven light source. Displacement map filter Displace a diffuse texture with an animated map transform rendered through the WebGPU filter path. Alpha mask filter Animate an alpha mask texture over a source bitmap using the WebGPU filter pipeline. Drop shadow filter Animated DropShadowFilter direction and distance rendered through the WebGPU filter path. Stacked filters Chain multiple filters on bitmap and sprite objects to exercise the new WebGPU stacked filter pipeline. Mesh Animated textured mesh deformation rendered through the WebGPU triangle mesh path. Honeycomb pattern Hexagon GraphicsPath cells filled with a repeating bitmap pattern, matching What's the Buzz reels.
